## 2026-10-31
- **AI 제공자 3곳 + 순서 설정**: Groq → Gemini → Cloudflare Workers AI. 환경변수 `LLM_ORDER`로 순서 변경, 요청별 `prefer`(진단용), 제공자별 30초 제한, 응답에 모델·소요시간·이전 실패 사유 포함. (ab58e12)
  - 같은 요청으로 측정: **Groq** 간단 0.3초·번역 0.6초·예문 1.2~2.0초 / **Workers AI(Llama 3.3 70B)** 0.3~0.8초·2.1~2.3초·6.3~7.0초 / **Gemini** 이전 측정 6~18초, 이번엔 연속 요청에서 429(할당량), 간헐적 400(지역 제한).
  - 한국어 설명 품질은 Groq(gpt-oss-120b)가 가장 좋고 Workers AI는 약간 어색한 문장이 있어 마지막 예비로 둠.
- **학습지 5~10주차 복원**: 옛 저장소 `asno27/language`에 직접 올렸던 데이터가 새 저장소에 빠져 있었음 → 10주차 복원. (ab58e12)
- **전체 사이트 테스트와 수정**: 🔊 듣기 버튼이 따옴표 문장에서 깨지던 문제(속성 주입 가능성 포함) 해결, 너무 긴 입력 안내, 빈 단어 저장 차단, FSI 자료실 링크, 접근성 라벨, 보안 헤더 추가. (044f1d9)
- 유튜브 번역 대안 결정: 클라우드에서 자막을 위장 접근으로 가져오는 방식은 채택하지 않음. 붙여넣기 모드·PC 자동 시작·내 파일 받아쓰기로 진행. (4da0895)
- 기획서 맨 위에 "남은 작업 총정리 & 우선순위" 작성. (0daeaa1)
- 학습지 소재 조사 문서와 다른 AI용 조사 프롬프트 작성.
- **유튜브 자막 붙여넣기 번역(PC 불필요)** 추가, 번역 중 화면을 가리던 로딩 표시 제거, 자막 여러 줄을 한 번에 번역. (Y-1)
- **AI 주소 남용 방지(R-1)**: IP별 1분·하루 사용 한도(D1), 한도 초과 안내(429), 출처 없는 요청은 더 낮은 한도.
- **연속 학습일·하루 목표·실수 기록(L-1, L-2)**: 학습 활동 기록, 🔥 헤더 배지와 패널, 달력 학습일 표시, 틀린 표현 저장(분석은 쌓인 뒤). 이 빌드는 Cloudflare가 시작하지 않아 빈 커밋으로 재시도해야 했음(R-1 때와 같은 현상).
