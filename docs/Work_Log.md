- **📉 내 실수 분석(L-3)**: 새 탭, 유형별 분석, 유형별 객관식 연습, 기록 삭제. 실제 AI로 확인했을 때 분석은 잘 맞았고 연습 문제는 9개 중 3개가 애매했음 → 프롬프트 강화(빈칸 1개 강제, 앱에서도 검증), 안내 문구 추가.
- **다른 AI(Gemini) 조사 결과 검증**: 학습지 소재 7곳을 직접 확인(4곳 자료실 추가, 3곳 보류), 가짜 예시 주소 1건·깨진 근거 주소 2건 발견. 받은 파일은 최종 보고서가 아니라 사고 과정 기록이었음. 오픈소스·데이터 라이선스(NGSL, Tatoeba, ts-fsrs, kuromoji, Meyda, CEFR-J)는 `docs/Tools_And_Data.md`에 정리.
- **📐 문법 설명 탭(L-4)**: 주제 선택·직접 입력, 레벨별 설명, 내 실수 탭 연결, 설명 저장. **AI가 만든 퀴즈에서 틀린 정답 키를 발견**(가정법 문제에 were) → 정답 없이 다시 풀어 보는 **자동 검수**를 추가하고 오답 이유 표시, 내 실수 연습에도 적용. 작업 중 `prompts.js`의 줄바꿈 이스케이프가 깨지는 실수를 배포 전에 발견해 수정.
- **Gemini 최종 보고서(프롬프트 B) 검증**: 차트 점수·퍼센트는 근거 없는 예시값, 1순위(IFrame API로 자막 추출)는 공식 문서상 불가능, Gemini 1.5 기준 한도는 낡음. 채택: ts-fsrs 검토, 소리 기반 발음 비교. (iOS 음성 인식 안내는 사용자가 iOS를 쓰지 않아 제외.) `docs/Tools_And_Data.md`, 프롬프트에 "숫자는 출처가 있을 때만" 규칙 추가.
