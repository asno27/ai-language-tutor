## 확인하지 못한 것 (기록에 적혀 있으나 직접 검증 못 함)
- **Common Voice 음성이 CC0** — Mozilla 문서로 알려진 사실이나 이번에 직접 읽지 못함.
- **Wiktionary 파생 사전(Kaikki.org)이 CC BY-SA** — 직접 읽지 못함.
- **쉐도잉 효과 연구**(Hamada 등): 기록에는 "초보자의 소리 인지에는 효과, 종합적 독해·말하기에는 보완 활동 필요"라는 요약이 있으나 논문 본문을 읽어 확인하지 못함. 인용하려면 원문 확인 필요.
- **Workers AI·Gemini·Groq 무료 한도**: 이미 별도로 확인함(`docs/Work_Log.md`).
