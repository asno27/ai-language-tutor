# 📝 학습지 소재 후보와 검증 기록

학습지(📖 인터랙티브 학습지 탭)에 쓸 수 있는 소재 출처를 **라이선스 기준**으로 정리한 문서입니다.
다른 AI에게 시킬 조사 프롬프트는 `docs/AI_Research_Prompts.md`에 있습니다.
**마지막 갱신: 2026-10-31 (다른 AI 조사 결과 1건 검증 반영)**

## 1. 학습지 한 개에 필요한 것

`data/worksheet.json`의 한 항목은 다음으로 이루어집니다.

| 필드 | 내용 |
|---|---|
| `week`, `title` | 번호와 제목 |
| `youtubeUrl` | 임베드용 유튜브 주소 (`https://www.youtube.com/embed/영상ID`) |
| `dictation[]` | 문장 3~5개: `sentence`(핵심 단어를 `{빈칸}`으로 표시), `ko`(한국어 해석), `hints[]`(빈칸별 한국어 힌트) |
| `shadowing` | `text`(따라 읽을 문단), `ko`(한국어 해석) |
| `source`, `license`, `sourceUrl` | 출처 한 줄(화면에 표시). `license` 값: `public-domain` · `cc0` · `cc-by` · `original`(AI 오리지널) · `unverified`(권리 확인 중). 새 학습지를 추가할 때 반드시 채울 것 |

→ 즉 **① 영상 ② 그 영상의 정확한 대사(스크립트) ③ 그 대사를 가공해도 되는 권리**가 모두 있어야 합니다.
공개 저장소에 올라가므로 ③이 가장 중요합니다.

## 2. 이용 방식 분류

| 라이선스 | 이 앱에서 할 수 있는 일 |
|---|---|
| 퍼블릭 도메인 / CC0 | ✅ 스크립트를 가공해 학습지로 **저장소에 포함**. 출처 표기는 예의로 남김 |
| CC BY | ✅ 가공 가능. **출처·저작자 표기 필수** |
| CC BY-SA | ✅ 가공 가능. 출처 표기 + 만든 학습지도 **같은 조건(SA)으로 공개** |
| CC BY-NC | ⚠️ 비영리 앱이면 가능하나 "NC" 해석이 애매 → 광고·후원을 붙이지 않는다는 전제로, 사용 전 판단 |
| CC BY-ND (예: TED) | 🔗 **가공 금지** → 문장을 잘라 빈칸을 만드는 것도 파생물로 볼 수 있음. 링크·공식 임베드만 |
| 모든 권리 보유 | 🔗 링크만. 본문 복사 금지 |

**AI가 만든 예시 콘텐츠**: StoryWeaver 예시 `27-the-moon-and-the-cap`은 주소는 200이나 앱이라 모든 주소가 200이어서 실존 여부 확인 불가, OpenLearn·American English 예시는 접속 차단으로 확인 불가, **NASA 유튜브 예시(`watch?v=nasa-latest-mission`)는 가짜**(영상 ID 형식이 아님, 조회 시 400).
**AI가 제안한 JSON의 오류**: OpenLearn을 `cc-by-nc`로 적었으나 실제는 NC-**SA**(동일조건) → 앱에 `cc-by-nc-sa` 배지를 추가해 반영.
**AI가 추천한 1순위(AI 오리지널 대화 + 브라우저 음성)** 는 이 문서 3-3과 같은 결론. 단 "정규식으로 동사·명사를 빈칸으로"는 품질이 낮으니, 빈칸 단어는 AI가 고르게 하는 편이 낫습니다(PDF 학습지 방식).

### 3-3. 저작권 문제가 없는 방식 — **AI 오리지널 대화 + 브라우저 음성(TTS)**
- AI가 레벨·주제에 맞는 **새 대화문**을 쓰고(저작권 문제 없음), 브라우저 음성 합성으로 읽어 주는 방식.
- 장점: 소재가 무한, 레벨·주제를 마음대로 정함, 라이선스 걱정 없음, 영상 없이도 가능.
- 단점: 원어민 실제 말투(속도·연음·억양)의 다양성은 영상 소재보다 떨어짐. TTS 음성은 기기마다 다름.
- 우리 앱의 `역할극`·`주제별 예문`이 이미 이 방식의 기반 → 학습지 형식으로 묶는 기능을 만들면 비용이 낮음. (기획서 W-2)

## 4. 추천 순서

1. **VOA Learning English → 학습지 만들기** (영상 + 퍼블릭 도메인 스크립트 → 현재 형식 그대로)
2. **AI 오리지널 대화 학습지** (라이선스 부담 없이 양을 늘릴 때)
3. LibriVox/Gutenberg 짧은 단편 → 쉐도잉 전용 문단
4. Simple English Wikipedia → 읽기·빈칸 (CC BY-SA 표기)
5. TED·BBC는 **자료실 링크**로만

## 5. VOA로 학습지 한 개 만드는 절차 (체크리스트)

1. VOA Learning English에서 **영상이 있고 스크립트 전문이 제공되는 항목** 선택 (뉴스 코너는 AP 등 외부 크레딧이 섞일 수 있으니 VOA가 직접 만든 코너 위주).
2. 항목 페이지에서 **크레딧**을 확인 — 외부 통신사 표시가 있으면 제외.
3. 유튜브 공식 채널의 같은 영상 주소에서 영상 ID를 얻어 `youtubeUrl`에 `https://www.youtube.com/embed/ID` 형식으로 기록(임베드가 허용된 영상만).
4. 스크립트에서 연속된 문장 3~5개를 골라 `dictation`을 만들고, 핵심 어휘(중급 이상 단어, 구동사, 연어)를 `{ }`로 표시. 한국어 해석과 빈칸별 힌트를 붙임.
5. 40~100단어 분량의 연속 문단을 `shadowing.text`로 정하고 한국어 해석 작성.
6. 항목에 출처 정보를 함께 기록 (`source`, `license`, `sourceUrl` — 아래 5-1 참고).
7. 로컬에서 학습지 탭을 열어 빈칸 채점·쉐도잉 동작 확인 후 커밋.

### 5-1. 출처 표기를 위한 `worksheet.json` 확장안 (제안, 미적용)
```json
{
  "week": 11,
  "title": "…",
  "youtubeUrl": "https://www.youtube.com/embed/…",
  "source": "VOA Learning English",
  "license": "public-domain",
  "sourceUrl": "https://learningenglish.voanews.com/…",
  "dictation": [ … ],
  "shadowing": { … }
}
```
- 학습지 화면 아래에 "출처: VOA Learning English · 퍼블릭 도메인"을 보여주는 한 줄 추가(`app.js`의 학습지 렌더링).
- 기존 1~10주차에는 `source`가 없으므로, **원본이 무엇인지 확인한 뒤** 채움.

## 6. 기존 학습지 1~10주차의 출처 (확인 필요)

- 제목으로 보아 BBC·CNN·유튜브 토론 영상 등에서 가져온 대사로 보이고, 문서에는 "소울영어 학습지"를 연동했다고 적혀 있습니다.
- **학습지 대사 문장을 공개 저장소에 두어도 되는지(사용 허락·출처)를 확인해야 합니다.** 본인이 직접 만든 교재가 아니라면, 
  ① 허락을 받거나 ② 해당 문장은 비공개로 두고(사이트에서 직접 입력/업로드하는 방식) ③ VOA 등 허용된 소재로 교체하는 방안이 있습니다.
- 확인 전까지는 현재 상태로 둡니다. (기획서 C-7)
