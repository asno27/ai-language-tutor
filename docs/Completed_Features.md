# 총 완료된 주요 기능 목록 (Completed Features)

본 문서는 지금까지 'AI Language Tutor' 프로젝트에 성공적으로 구현되어 작동 중인 기능들을 정리한 문서입니다. 새로운 기능을 추가할 때마다 이곳으로 이동하여 기록합니다.

---

## 1. ✍️ 영작 교정 및 피드백 (Writing)
- 사용자가 영어 문장을 입력하면, 문법 오류를 교정해주고 더 자연스러운 원어민 표현으로 개선해줍니다.

## 2. 🌐 한국어 번역 및 표현 추천 (Translation)
- 한국어를 영어로, 영어를 한국어로 자연스럽게 번역하며, 비슷한 뉘앙스의 다른 영어 표현도 함께 추천해줍니다.

## 3. 📚 나만의 단어장 (Vocabulary)
- 검색한 단어와 학습하고 싶은 단어를 모아서 나만의 단어장을 구성합니다.
- **[관심사 맞춤 예문]**: 사용자의 관심사(예: IT, 게임, 여행 등)를 입력하면 해당 관심사에 맞춘 단어 예문을 생성합니다.
- 복습 모드를 통해 암기 여부를 체크하고, 원어민 발음(TTS)을 들을 수 있습니다.

## 4. 🗣️ 영어 발음 튜터 (Pronunciation)
- 사용자가 목표 문장을 직접 마이크로 읽으면(STT), AI가 인식한 음성 텍스트와 원본 문장을 비교하여 점수와 발음 교정 팁을 제공합니다.

## 5. 📅 오늘의 영어 추천 (Daily Sentence)
- 매일 새로운 영어 문장, 번역, 그리고 해당 문장을 사용하는 생생한 문맥(Context)을 추천받아 학습할 수 있습니다.

## 6. 💬 뉘앙스 질문 챗봇 (Nuance Chatbot)
- "see vs look" 처럼 헷갈리는 영어 단어나 표현의 미묘한 차이를 알면 우측 하단의 플로팅 버튼(FAB)을 통해 언제든 AI에게 질문할 수 있습니다.

## 7. 📱 모바일 UI/UX 개선 (Mobile UI Fix)
- 모바일(스마트폰) 환경에서 화면을 가리던 세로형 내비게이션 메뉴를 가로 스크롤(Horizontal Scroll) 방식으로 개선하여 접근성을 높였습니다.

## 8. 📝 인터랙티브 학습지 & 섀도잉 (Worksheet)
- '주간 서울 영어 학습지'를 연동하여 주차별 콘텐츠를 제공합니다. (1~10주차 연동 완료)
- 유튜브 영상 기반의 빈칸 영작 퀴즈 채점 기능.
- 최종 섀도잉 탭에서 AI가 발음과 유창성을 체크해 주는 섀도잉 기능 포함.

## 9. 🔍 원클릭 미니 사전 & 즉시 단어장 추가 (Mini Dictionary)
- 화면에 출력된 어떤 영어 텍스트든 클릭(터치)하면 조그마한 말풍선이 떠서 단어 뜻을 알려줍니다.
- 팝업 창의 [단어장에 추가] 버튼을 눌러 언제든 즉시 내 단어장으로 저장할 수 있습니다.

## 10. 🎥 유튜브 자막 서버 (Local PC 우회 아키텍처 구축)
- 유튜브 영상 링크를 입력하면 로컬 PC 백엔드를 통해 영상의 공식 자막(CC)을 추출하고 전체 스크립트를 한국어와 매칭하여 번역합니다.
- Render 클라우드 서버가 유튜브 봇으로 영구 차단됨에 따라, 사용자의 윈도우 PC를 백엔드로 활용하는 **Local Terminal Architecture**로 완전 전환했습니다.
- **Ngrok 정적 도메인 연결**: 폰에서 접속하기 위해 평생 고정 주소를 발급받아 `run_server.bat`을 통해 자동화 연결.

## 11. 🎙️ 유튜브 자막 없는 영상 오디오 추출 (Groq Whisper)
- 유튜버가 공식 자막을 올리지 않은 영상이라도, 백엔드가 오디오를 직접 추출한 뒤 Groq API(Whisper-large-v3)를 사용해 초고속으로 자체 오디오 받아쓰기(Transcription)를 수행해 번역을 가능하게 합니다.

## 12. 🧠 AI 듀얼 코어 번역 시스템 (Gemini + Groq Fallback)
- 구글 Gemini API의 서버 마비(503 에러) 등 잦은 접속 불안정에 대비하여 번역 관제탑을 로컬 PC로 옮겼습니다.
- Gemini 서버가 뻗을 경우, 즉시 메타의 `llama-3.1-70b-versatile` (Groq API) 모델로 스위칭하여 에러 없이 무중단 번역 결과를 앱에 제공합니다.

## 13. 🔀 백엔드 기능별 분리 — PC 없이 24시간 AI 기능 (Phase 1.9, 2026-09-27)
- 번역·교정·사전·오늘의 영어 등 AI 텍스트 기능(`/api/llm`)을 Cloudflare Worker로 이전. **PC가 꺼져 있어도 동작.**
- 사이트 주소: `https://ai-language-tutor.kaipromp.workers.dev` (GitHub `asno27/ai-language-tutor`에 push하면 자동 배포)
- Gemini 1순위 → Groq 2순위(여러 모델 순차 시도). API 키는 Cloudflare Secret에 저장.
- 한국 요청이 홍콩 서버에서 처리되어 Gemini가 거부하던 문제를 Placement(`gcp:us-central1`) 설정으로 해결.
- 유튜브 자막(`/api/youtube`)만 PC + ngrok에 남김. PC가 꺼져 있으면 "PC 서버를 켜 주세요" 안내.

## 14. 📅 오늘의 영어 추천 — 반복 방지 & 달력 아카이브 (2026-09-27)
- 매번 여행·비즈니스·일상별로 구체적인 상황을 무작위로 골라 문장을 생성하고, 뻔한 교과서 관용구는 피하도록 지시. 이 기능만 temperature 1.0.
- 받은 추천은 날짜별로 `localStorage`의 `daily_archive`에 저장. 최근 30문장은 AI에게 "반복 금지" 목록으로 전달.
- [📅 지난 추천 보기] → 월별 달력에서 추천받은 날짜(세트 수 표시)를 눌러 그날 문장을 다시 보고, 듣기·쉐도잉·단어 클릭 사전 사용 가능.
- ⚠️ 기기(브라우저)별 저장이라 휴대폰과 PC의 기록은 서로 공유되지 않음.

## 15. 🎭 역할극 회화 (Phase 2.1, 2026-09-27)
- 카페 주문, 공항 입국심사, 호텔 체크인, 식당 주문, 병원 진료, 영어 면접, 환불 요청 + 직접 입력한 상황에서 AI가 상대역을 맡아 대화.
- 난이도 3단계(초급·중급·고급)에 맞춰 AI 대사 길이와 어휘를 조절.
- 사용자가 대답할 때마다 더 자연스러운 표현, 한국어 설명, 점수를 표시. 한국어로 쓰면 "영어로는 이렇게 말해요"로 알려줌.
- 다음에 할 수 있는 대답 예시(칩), 🎤 음성으로 대답하기, AI 대사 자동 읽기(TTS), 해석 보기, 단어 클릭 사전 지원.
- 프롬프트: `js/prompts.js`의 `roleplay` 모드, 상황 목록 `ROLEPLAY_SCENARIOS`. temperature 0.8, 최근 12개 대화만 전송.

## 16. 📄 PDF로 학습지 만들기 (Phase 2.2, 2026-09-27)
- 학습지 탭에서 영어 지문 PDF를 올리면 구간별로 한국어 요약, 핵심 단어(지문에 강조 표시, 단어장 저장), 빈칸 채우기 3문제, 쉐도잉 문장을 자동 생성.
- PDF 파일은 브라우저 안에서만 읽고, 추출한 글자만 AI 분석에 사용. 결과는 이 기기에 저장되어 같은 PDF는 다시 분석하지 않음.

## 17. 🎯 단어별 발음 채점 (Phase 2.3, 2026-09-27)
- 따라 읽은 문장을 원문과 단어 단위로 비교해 정확/비슷함/틀림/빠짐을 색으로 표시하고 점수를 계산 (API 호출 없음, 즉시 결과).
- 색이 있는 단어를 누르면 원어민 발음(TTS) 재생. 자세한 조언은 [💡 AI 발음 팁 받기]로 요청.
- 발음 탭, 오늘의 영어 쉐도잉, 주간 학습지 쉐도잉, PDF 쉐도잉에 공통 적용.

## 18. 🔄 기기 간 동기화 (Phase 2.5, 2026-09-27)
- 단어장 탭 하단에서 [이 기기에서 동기화 시작하기] → 26자리 동기화 코드 생성. 다른 기기에서 코드를 입력하거나 [📱 QR]을 찍으면 연결.
- 단어장(복습 기록 포함), 오늘의 영어 달력 기록, 관심사가 기기 간에 합쳐짐. 같은 단어는 최근 수정한 쪽이 이기고, 삭제도 다른 기기에 반영.
- 저장·삭제 2초 뒤 자동 전송, 앱으로 돌아오거나 인터넷이 다시 연결되면 자동 동기화.
- 서버(Cloudflare D1)에는 코드 원문이 아닌 해시만 저장. 코드를 아는 사람은 데이터에 접근할 수 있으므로 비밀번호처럼 보관.
- 함께 수정: 미니 사전 [단어장에 추가]가 빈 단어를 저장하던 버그, 관심사 맞춤 예문이 단어장에 저장되지 않던 문제.
